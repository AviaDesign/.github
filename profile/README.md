# AviaDesign

Independent aviation focused software and IT services from Finland. We design, build, and maintain web applications and platforms for operators, training organizations, and aviation communities worldwide.

Our flagship product, AirwaySim, is an airline management simulation used by a worldwide user base, including universities and aviation professionals. In addition to product development, we provide IT administration and infrastructure expertise for aviation clients, with a strong focus on long-term maintainability, reliability, and practical solutions.
